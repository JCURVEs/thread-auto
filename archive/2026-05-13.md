## [arXiv AI] 스패셜 프라이밍이 의미 프롬프팅을 상회한다: 차트 데이터 추출의 정확성을 높이는 그리드 기반 접근법

**분야:** 연구 논문 | **중요도:** 8점

**요약:**  
과학 차트에서 데이터를 자동으로 추출하는 것에는 대규모 문헌 분석에서 중요한 과제이다. 다중 모달 큰 언어 모델(LLM)이 약속을 보인다 하더라도, 그들의 정확성은 비표준화된 차트에 대해서는 ancora 도전과제로 남아있다. 이 논문에서는 높은 수준의 의미 프라이밍(high-level semantic priming) 대신에 낮은 수준의 공간 프라이밍(low-level spatial priming)을 사용하여 모델의 성능을 향상시키는 최선의 전략을 찾으려고 한다. 공간 프라이밍 방법은 차트 이미지에 좌표 그리드를 오버레이 하는 것이다. 이 실험에서는 의미 프라이밍 방법을 사용했지만 통계적으로 유의한 결과가 나오지 않았다. 하지만 공간 프라이밍 방법은 차트 데이터 추출 오류(SMAPE)를 25.5%에서 19.5%로 줄였다(p < 0.05). 따라서 공간 프라이밍 방법은 현재의 다중 모달 모델에서 의미 프라이밍보다 더 효과적이고 신뢰할 수 있다.

**쉬운설명:**  
차트에 격자 모양의 그리드를 넣으면, 인공지능이 차트 값을 더 정확하게 읽을 수 있습니다.

## [arXiv AI] 자동评분법을 이용한 보상: 암묵적 선호도에서 명시적 다중모달 생성 기준까지

**분야:** 연구 논문 | **중요도:** 9점

**요약:**  
다중모달 생성 모델을 인간의 선호도와 일치시키는 것은 조합적이고 다차원적인 인간 판단 구조를 존중하는 보상 신호가 필요합니다. 현재의 강화학습(Human Feedback, RLHF) 접근 방식은 이 구조를 스칼라 또는 페어 와이즈 레이블로 줄여, 미묘한 선호도를 opak한 매개 변수 프록시로 축소하고 보상 хак킹의 脆弱性를 노출합니다. 최근의 평가기준-보상(Rubrics-as-Reward, RaR) 방법은 명시적 기준을 통해 이 구조를 회복하려고 시도하지만, 동시에 신뢰할 수 있고 확장성이 있으며 데이터 효율적인 평가기준을 생성하는 것은 여전히 열린 문제입니다. 본 논문은 자동 평가기준을 이용한 보상(Auto-Rubric as Reward, ARR) 프레임워크를 제안하며, 이는 암묵적 가중치 최적화를 명시적이고 기준 기반의 분해로 재구성합니다. 페어 와이즈 비교 전에 ARR은 큰 언어모델(VLM)의 내부화된 선호도 지식을 특정 프롬프트에 대한 평가기준으로 외부화하며, 이는 전체적인 의도를 독립적으로 검증 가능한 품질 차원으로 번역합니다. 이러한 암묵적 선호도 구조를 검사 가능한, 해석 가능한 제약으로 전환하여 평가 편향을 크게 감소시킵니다. 이를 생성 모델 훈련으로 확장하기 위해 평가기준 정책 최적화(Rubric Policy Optimization, RPO) 방법을 제안하며, 이는 ARR의 구조적인 다차원 평가를 강력한 이진 보상으로 추출하여 정책 그래디언트를 안정화합니다. 텍스트-이미지 생성 및 이미지 편집 벤치마크에서 ARR-RPO는 페어 와이즈 보상 모델과 VLM 심판보다 성능이 우수하여 암묵적 선호도 지식을 명시적인 구조적인 평가기준으로 외부화하여 더 신뢰할 수 있고 데이터 효율적인 다중모달 정렬을 달성할 수 있음을 보여줍니다.

**쉬운설명:**  
즉, 컴퓨터가 사람과 같은 선호도를 가지도록 교육하는 새로운 방법을紹介합니다. 이 방법은 컴퓨터가 명확하게 평가 기준을 이해하도록 가르쳐, 더 나은 성능을 낼 수 있습니다.

즉, 기존 의미론적 임베딩이 아닌, 사람의 선호도를 잘 담아내는 임베딩 기술을 개발해야 한다는 뜻입니다.

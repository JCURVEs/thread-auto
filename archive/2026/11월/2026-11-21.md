## [Hugging Face] 하니스 어댑터: RL 기반 LoRA로 에이전트 성능 및 토큰 효율 극대화

**분야:** 오픈소스 도구 | **중요도:** 8점

**원문발행일:** 2026-11-20T00:00:00+00:00

**수집일:** 2026-11-21

**요약:**  
특정 에이전트 하니스와 작업 분포에 맞춘 강화학습(RL)을 통해 LoRA 어댑터를 학습하는 방법을 제시합니다. Qwen3.8-27B 모델을 대상으로 Pi, OpenCode, Hermes Agent 세 가지 하니스에서 실험한 결과, Terminal-Bench 2.1 점수가 39%에서 55%로 상승했습니다. 동시에 평균 토큰 사용량은 2.9K에서 1.5K로 감소하여 추론 효율성이 크게 개선되었습니다. OpenEnv와 TRL을 활용한 재현 가능한 데이터 파이프라인 및 Docker 이미지 구성법을 공유합니다.

**쉬운설명:**  
특정 도구(하니스)를 잘 쓰도록 AI에게 맞춤 훈련을 시켜서, 더 적은 노력으로 더 정확하게 일하게 만드는 방법입니다.

## [Hugging Face] AWS Trainium3에서 LTX-2.5 기반 영상 생성 파이프라인 구현 및 성능 검증

**분야:** 비전/멀티모달 | **중요도:** 4점

**원문발행일:** 2026-11-27T00:00:00+00:00

**수집일:** 2026-11-27

**중요도보정:** 6점 → 4점 (business_signal_cap)

**요약:**  
AWS Trainium3 하드웨어에서 Hugging Face의 LTX-2.5 모델을 활용해 영상과 음성을 동시에 생성하는 실험을 수행했습니다. 모델 로딩 후 10초 분량의 2048×1024 해상도 영상 생성에 22~23초가 소요되어, LTX 공식 API의 1080p 생성 시간(23.7초)과 유사하거나 약간 빠른 성능을 보였습니다. JSON 기반 스토리보드 형식의 입력을 받아 샷 간 프레임 연결을 통해 일관된 단편 영화를 생성하는 워크플로우를 구축했습니다. 해당 파이프라인은 diffusers 라이브러리의 LTX2Pipeline 및 LTX2ConditionPipeline을 활용하여 구현되었습니다.

**쉬운설명:**  
즉, 최신 AI 칩을 이용해 텍스트 설명만 주면 영상과 소리가 함께 담긴 짧은 영화를 자동으로 만들어 주는 기술을 시험해 본 것입니다.

## [OpenAI] OpenAI, Python 기반 분산 스토리지 플랫폼 Habitat로 초당 7,000만 건 요청 처리

**분야:** API/인프라 | **중요도:** 4점

**원문발행일:** 2026-09-11T10:00:00+00:00

**수집일:** 2026-09-12

**중요도보정:** 6점 → 4점 (business_signal_cap)

**요약:**  
OpenAI는 제품 엔지니어가 데이터베이스 관리 없이 데이터를 접근할 수 있도록 Python 라이브러리에서 출발한 Habitat를 글로벌 분산 스토리지 플랫폼으로 확장했습니다. 현재 Habitat는 40개 이상의 지리적 지역에서 500PB 이상의 데이터를 관리하며, 주 10억 명 이상의 사용자와 초당 7,000만 건 이상의 요청을 처리합니다. 이 시스템은 Azure Cosmos DB를 백엔드로 사용하되, 스키마 조회, 라우팅, 인증, 암호화, 직렬화, 연결 풀링 등 복잡한 저장소 로직을 서비스 단위로 분리하여 추상화했습니다. 이를 통해 OpenAI는 연 10배 이상의 급격한 성장 속에서도 기존 스택의 성능을 극대화하며 안정성을 유지하는 데 성공했습니다.

**쉬운설명:**  
즉, OpenAI의 모든 앱이 필요한 정보를 빠르고 안전하게 찾을 수 있도록, 복잡한 데이터 보관함을 자동으로 정리하고 관리해 주는 '초고속 디지털 비서' 역할을 하는 시스템이라는 뜻입니다.

## [NVIDIA Korea] NVIDIA Nemotron과 Palantir 온톨로지 기반 소버린 공급망 AI 스택 구축

**분야:** 에이전트/자동화 | **중요도:** 4점

**원문발행일:** 2026-09-11T03:21:41+00:00

**수집일:** 2026-09-12

**중요도보정:** 6점 → 4점 (business_signal_cap)

**요약:**  
NVIDIA는 Palantir와 협력하여 Nemotron 오픈 모델과 Palantir Foundry, AIP를 통합한 공급망 최적화 AI 스택을 개발했습니다. 이 시스템은 NVIDIA의 자체 공급망에 우선 적용되어 웨이퍼부터 토큰까지의 전 과정을 가속화하며, 수백만 개의 부품과 수천 개 공급업체를 조율합니다. 기업은 NVIDIA NeMo 데이터 라이브러리를 활용해 자체 운영 데이터로 Nemotron을 사후 학습하여, 데이터 소유권을 유지하면서 맞춤형 의사결정 지원을 받을 수 있습니다. 또한 cuOpt 소프트웨어와 NeMo AutoModel, NeMo RL 라이브러리가 결합되어 피드백 루프를 통해 모델이 지속적으로 개선되는 구조로 설계되었습니다.

**쉬운설명:**  
즉, 복잡한 공장 물류를 관리하는 똑똑한 도우미로, 각 회사만의 비밀 데이터로 훈련시켜서 물품이 어디에 있는지, 언제 도착하는지 가장 잘 아는 개인 비서 역할을 한다는 뜻입니다.

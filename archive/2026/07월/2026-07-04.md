## [arXiv AI] Wiola 아키텍처: 효율적인 소_scale 언어 모델

**분야:** LLM 출시 | **중요도:** 9점

**요약:**  
Wiola 아키텍처는 기존 언어 모델 가족과 구조적으로 아무 관련이 없는 полностью 원래의 소_scale 언어 모델입니다. Wiola아키텍처는 5가지 독립적으로 새로운 구성 요소를 도입합니다. 첫째, 3차원 나선형 다중체(나선형 회전 위치 인코딩, Spiral Rotary Positional Encoding)에서 토큰 위치를 삽입하여 절대적, 상대적, 계층적位置 신호를 결합합니다. 둘째, 게이트 교차 레이어 어텐션(Gated Cross-Layer Attention)을 제공하여 각 디코더 레이어에서 두 개의 이전 레이어의 요약된 버전에 대한 소프트 교차 어텐션 액세스를 허용합니다. 세째, 적응적 토큰 병합(Adaptive Token Merging)을 통해 네트워크 중간 레이어에서 의미적으로冗余한 인접 토큰을 동적으로 병합하여 어텐션 복잡성을 정보 손실 없이 감소시킵니다. 넷째, 이중 스트림 피드 포워드(Dual Stream Feed-Forward)를 사용하여 일반적인 다층 퍼셉트론(다층 퍼셉트론, MLP)을 대체하여 두 개의 병렬 스트림을 학습된 차원별 게이트로 융합합니다. 다섯째, WiolaRMSNormalize를 사용하여 각 차원에 대해 학습된 오프셋 벡터를 도입하여 표현 붕괴를 방지합니다. Wiola는 4가지 크기(120M, 360M, 700M, 1.5B 파라미터)로 출시되며, Hugging Face Transformers 생태계와 완전히 호환됩니다.

**쉬운설명:**  
이.architecture는 기존 언어 모델에서 더 나은 성능을 내주는 새로운 소_scale 언어 모델 아키텍처이다.

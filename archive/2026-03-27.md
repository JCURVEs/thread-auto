## [arXiv AI] 대화에서의 다중모달 감정 인식 위한 동적 융합 인식 그래프 합성곱 신경망

**분야:** 연구 논문 | **중요도:** 9점

**요약:**  
대화에서의 다중모달 감정 인식은 여러 모달리티(예: 텍스트, 오디오, 이미지 등)에서 발화자들이 표현하는 감정을 식별하고 이해하는 것을 목표로 합니다. 기존 연구는 그래프 합성곱 신경망(Graph Convolutional Neural Network, GCN)이 발화자 간의 종속성을 모델링하여 다중모달 감정 인식 성능을 향상시킬 수 있음을 보여주었습니다. 그러나 기존 방법들은 일반적으로 다중모달 특성을 처리하기 위해 고정된 매개변수를 사용하여 다양한 감정 유형에 대한 융합의 동적인 특성을 무시하며, 이는 모델이 다중 감정 카테고리 간의 성능 균형을 강요함으로써 일부 특정 감정에 대한 모델의 성능을 제한합니다. 따라서 본 연구는 대화에서의 다중모달 감정 특성에 대한 강인한 인식을 위해 동적 융합 인식 그래프 합성곱 신경망(DF-GCN)을 제안합니다. 특히, DF-GCN은 그래프 합성곱 신경망에普通微分방정식(Ordinary Differential Equations, ODE)을 통합하여 발화 상호작용 네트워크 내에서 감정 종속성의 동적인 특성을 캡처하고, 발화 全局 정보 벡터(Global Information Vector, GIV)가 생성한 프롬프트를 사용하여 다중모달 특성의 동적 융합을 안내합니다. 이는 모델이 각 발화 특성을 처리할 때 매개변수를 동적으로 변경할 수 있으므로, 추론 단계에서 다른 감정 카테고리에 대해 다른 네트워크 매개변수를 장착할 수 있어, 더 유연한 감정 분류와 모델의 일반화 능력을 향상시킵니다. 두 개의 공공 다중모달 대화 데이터셋에서 수행된 포괄적인 실험은 제안된 DF-GCN 모델이 우수한 성능을 발휘하며, 도입된 동적 융합 메커니즘에서 크게 이익을 얻음을 확인합니다.

**쉬운설명:**  
즉, 여러 사람 사이의 대화에서 각 사람이 어떤 감정을 가지고 있는지 더 잘 알아보려고 그래프 합성곱 신경망을 사용한 새로운 방법을 개발한 것입니다.

**출처:** https://arxiv.org/abs/2603.22345

**분야:** 연구 논문 | **중요도:** 9점

**요약:**  
最近의 연구에서, 의료 분야에서 大語言模型의 평가를 위한 새로운 접근법이 제시되었습니다. 기존의 정적 벤치마크 방식은 반복적으로 수행하기에 비용이 많이 든다며, 데이터 오염에 취약하고 정밀한 성능 추적에 적합하지 않습니다. 따라서, 연구자들은 항목 반응 이론(아이템 응답 이론, IRT) 기반의 컴퓨터 적응형 테스트(Computerized Adaptive Testing, CAT) 프레임워크를 제안했습니다. 이 연구에서는 몬테카를로 시뮬레이션을 통해 최적의 CAT 설정을 식별하고, 38개의 大語言模型에 대한 인간 기반 의료 항목 은행을 사용하여 실증 평가를 수행했습니다. 각 모델은 전체 항목 Ngân과 적응형 테스트를 모두 완료하였으며, 적응형 테스트는 실시간 능력 추정치를 기반으로 항목을 동적으로 선택하여 미리 정의된 신뢰도 임계값(표준 오차 <= 0.3)에 도달할 때까지 계속되었습니다. 결과는 CAT로 추출된 숙련도 추정치가 전체 은행 추정치와 거의 완벽하게 상관関係이 있었으며(r = 0.988), 항목의 1.3%만 사용했음에도 불구하고 이는 평가 시간을 수 시간에서 수 분으로 단축시키고 토큰 사용 및 계산 비용을 크게 giảm輕했으며, 모델 간의 성능 순위를 유지했습니다. 이 연구는 大語言模型 의료 지식에 대한 신속하고 저비용의 벤치마킹을 위한 심리 측정 프레임워크를 확립합니다. 제안된 적응형 방법론은 표준화된 선별 및 지속적인 모니터링 도구로 의도되며 실제 임상 검증 또는 안전 지향 연구의 대안은 아닙니다.

**쉬운설명:**  
즉, 의료 분야에서 인공지능의 지식을 빠르고 정확하게 측정하는 새로운 방법입니다.

## [arXiv NLP] 마스킹을 넘어서: 삭제-삽입 과정을 통한 효율적이고 유연한 확산 언어 모델

**분야:** 연구 논문 | **중요도:** 9점

**요약:**  
마스킹 기반 확산 언어 모델(MDLM)은 언어 모델링에서 약속을 보였지만, 계산 효율성과 생성 유연성이 마스킹 패러다임에 의해 제한됩니다. 본論문에서는 삭제-삽입 확산 언어 모델(DID)을 제안하여 토큰 삭제와 삽입을 이산 확산 과정을 통해 엄밀하게 공식화하며, 기존의 MDLM에서 마스킹과 안마스킹 과정을 대체합니다. DID는 두 가지 주요 계산 오버헤드를 제거하여 훈련과 추론 효율성을 개선하며, 가변 길이 시퀀스를 기본적으로 지원하고, 생성 중에 삽입에 의한 자기-수정 메커니즘을 제공합니다. DID를 훈련하기 위해, 토큰 삽입 작업에 점수를 할당하는 점수 기반 접근 방식을 설계하고, 적절한 훈련 목표를 도출합니다. 이러한 목표는 부분 시퀀스 카운팅 문제를 포함하며, 이것을 동시 다이나믹 프로그래밍 알고리즘을 통해 효율적으로 해결합니다. 실험 결과는 DID가 MDLM 및 기존 삽입 기반 언어 모델에 비해 모델링 성능, 샘플링 품질 및 훈련/추론 속도에서 우위를 보임을 보여줍니다.

**쉬운설명:**  
즉, 삭제-삽입 확산 언어 모델은 마스킹을 사용하지 않고, 토큰을 삭제하고 삽입하여 언어 모델링을 더 효율적이고 유연하게 만드는 새로운 접근법입니다.

**출처:** https://arxiv.org/abs/2603.23507

## [arXiv NLP] 다중 모달 언어 모델에서 시각 공간적 관점 취하기

**분야:** 연구 논문 | **중요도:** 8점

**요약:**  
최근 다중 모달 언어 모델(Multimodal Language Model, MLM)이 사회적 및 협력적 환경에서 점점 더 많이 사용되면서, 이러한 모델의 관점 취하기 능력을 평가하는 것이 매우 중요합니다. 기존의 벤치마크는 주로 텍스트 기반의 장면 이해나 정적 장면 이해에 의존하여, 시각 공간적 관점 취하기(Visuospatial Perspective Taking, VPT)를 거의 탐구하지 않았습니다. 본 연구에서는 인간 연구에서 사용된 평가 과제 두 가지를 다중 모달 언어 모델에 적용하여, 이 모델들의 VPT 능력을 평가하였습니다. 평가 결과, 다중 모달 언어 모델은 다른 사람의 관점을 채택하기 위해 자기 관점을 억제해야 하는 2단계 VPT 에서 큰 결함을 보입니다. 이러한 결과는 현재 다중 모달 언어 모델이 다른 관점을 표현하고推論하는 능력의 극심한 제한을 暴露하며, 협력적 환경에서 이러한 모델을 사용하는 데 중요한 의미를 가지고 있습니다.

**쉬운설명:**  
즉, 인공지능이 다른 사람의 시각에서 상황을 이해하고 공감하는 능력이 부족하다는 뜻입니다.
